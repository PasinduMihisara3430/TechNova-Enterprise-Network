
# TechNova Solutions – Enterprise Network Design & Implementation

## Project Overview
An academic group project focused on designing and simulating a secure and scalable enterprise network using Cisco Packet Tracer.

The network connects a three-floor headquarters with a remote branch office through a WAN connection.

## Technologies & Concepts
- Cisco Packet Tracer
- IPv4 Addressing and VLSM
- IPv6 Dual-Stack Configuration
- VLANs and Inter-VLAN Routing
- Single-Area and Multi-Area OSPF
- OSPF MD5 Authentication
- NAT/PAT
- DHCP Configuration
- Port Security, BPDU Guard and DHCP Snooping
- Network Troubleshooting
- Multicast Network Design (PIM Sparse Mode and IGMP)

## My Contributions
- Designed and configured IPv6 dual-stack addressing
- Implemented Multi-Area OSPF routing
- Diagnosed and resolved OSPF authentication issues

## Testing & Verification
- Inter-VLAN connectivity testing
- Headquarters-to-branch connectivity
- OSPF neighbor and routing verification
- DHCP and NAT verification
- OSPF troubleshooting

## Limitations
PIM Sparse Mode multicast routing was documented but could not be simulated due to Cisco Packet Tracer limitations.
